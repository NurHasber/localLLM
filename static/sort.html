1. Папка на диске

Путь, который видит Python-сервер (не выбор файлов в браузере). Подписи пишутся в logs/sort/*.jsonl — можно продолжить после паузы. Копии пойдут в подпапку sorted, оригиналы не трогаем.

2. JoyCaption

Короткие теги для сортировки, не промпт для редактора. Не запускайте, пока идёт генерация Qwen (~15–25 мин на ~200 фото, если GPU свободен).

Сначала сканируйте папку.

    3. Папки

    Подписи JoyCaption без наших категорий. Группы называются по тексту подписей, без списка «люди / животные / аниме». Старые JSONL уже с прежним промптом — чтобы увидеть новый разбор, подпишите папку заново.

    После подписей нажмите «Сгруппировать». Ollama может думать несколько минут — здесь будет таймер и пакеты.
