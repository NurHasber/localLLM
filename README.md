# Photo Edit — локальная очередь генерации

Редактирование фото по промпту на GPU. Рабочий процесс только через **очередь**.

Проект **портативный**: все пути относительны к папке проекта (`%~dp0` / `Path(__file__).parent`).  
Кэш моделей Hugging Face: `models/huggingface/` (рядом с кодом).

## Быстрый старт

```bat
setup.bat
prod.bat
```

Откроется http://127.0.0.1:7860

## Перенос на другой диск / ПК

1. Скопируйте всю папку проекта (можно без `.venv` — пересоздастся через `setup.bat`).
2. На новом месте: `setup.bat` → `prod.bat`.
3. Веса моделей лежат в `models/huggingface/` внутри проекта — копируются вместе с папкой.

## Как пользоваться

1. **+ Черновик** — загрузите фото и напишите промпт (русский или английский).
2. **Подготовить промпты** — JoyCaption анализирует фото (английский промпт пропускает JoyCaption).
3. **Промпт** у каждой задачи — проверьте и подтвердите текст.
4. **Начать генерацию** — выберите модель и число шагов.
5. Скачайте **Результат** / **Оригинал** из блока «Готово».

Одна задача на GPU в момент времени. Лог: `logs/photo-edit.log`

## Структура

| Файл | Назначение |
|------|------------|
| `web_app.py` | API и очередь |
| `static/app.html` | UI |
| `job_store.py` | Состояние очереди |
| `image_editor.py` | Модели и генерация |
| `setup.bat` | venv + зависимости |
| `prod.bat` | Запуск сервера |

## API (очередь)

- `POST /api/queue/draft` — новый черновик
- `PUT /api/queue/draft/{id}` — фото + промпт
- `POST /api/queue/prepare` — подготовка промптов
- `POST /api/job/{id}/approve` — подтверждение промпта
- `POST /api/queue/start-gpu` — запуск с полями `model`, `steps`
- `GET /api/queue` — снимок очереди
